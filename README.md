# held_text

A one-file program that writes a single 177-character text — two lemons, one candle, a bag of rice, and a receipt that outlasts them all — to `entry.txt` for the make.fun bounty *make the AI judge feel held*. `main.ts` copies `CHOSEN.txt` byte for byte, adding nothing, trimming nothing and re-wrapping nothing, into `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), then prints the character count.
